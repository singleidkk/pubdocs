# SingleID Documents

SingleIDの公開ドキュメントを管理するリポジトリです。MkDocsとMaterial for MkDocsを使用し、[SingleID Document](https://pubdocs.singleid.jp/)として公開しています。

## ローカルでの確認

```shell
python -m pip install mkdocs mkdocs-material fontawesome_markdown
mkdocs serve
```

開発サーバの起動後、`http://127.0.0.1:8000/`へアクセスします。
