# チケットのステータス

文書更新日:2026-07-29

| ステータス | 説明 |
| :-- | :-- |
| **新規** | サポート担当者の割り当てを待っている状態です。 |
| **対応中** | サポート担当者が対応している状態です。 |
| **お客様ご対応待ち** | お客様による確認、対応、コメントを待っている状態です。 |
| **エスカレーション中** | 別の部署または組織へ問い合わせている状態です。回答まで時間がかかる場合があります。 |
| **解決** | チケットの内容が解決し、終了を待っている状態です。原則として、3営業日の間にお客様からコメントがなければ終了します。 |
| **終了** | チケットへの対応が終了した状態です。追加の確認が必要な場合は、新しいチケットを作成してください。 |
