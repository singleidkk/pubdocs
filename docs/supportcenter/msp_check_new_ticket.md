# 新規チケット内容の確認

文書更新日:2026-07-29

1. **マイページ**をクリックします。
    [![Screenshot](/images/clipboard-202203040945-bpsgk.png)](/images/clipboard-202203040945-bpsgk.png)

2. **担当しているチケット**セクションで、ステータスが**新規**のチケットを確認します。**プロジェクト**列には、お問い合わせ元のお客様の会社名が表示されます。
3. **題名**をクリックし、チケットの詳細を表示します。
    [![Screenshot](/images/clipboard-202203040947-bhjpw.png)](/images/clipboard-202203040947-bhjpw.png)

!!! warning
    新しいチケットが作成されると、MSP提供事業者のグループに所属するユーザ全員へメールで通知されます。チケットを確実に確認し、担当者を割り当てる運用ルールを定めてください。
