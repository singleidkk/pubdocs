# チケットへのコメントの追加

文書更新日:2026-07-29

1. **マイページ**をクリックします。

2. **報告したチケット**セクションで、対象のチケットの題名をクリックします。ステータスが**お客様ご対応待ち**の場合は、サポート担当者からの依頼内容を確認してください。
    [![Screenshot](/images/clipboard-202203040847-wuhoc.png)](/images/clipboard-202203040847-wuhoc.png)

3. **編集**をクリックします。
4. コメントを入力し、**送信**をクリックします。
    [![Screenshot](/images/clipboard-202203040854-3tlzs.png)](/images/clipboard-202203040854-3tlzs.png)

!!! info
    **参照**をクリックしてファイルを添付できます。コメント欄へ画像を貼り付けることもできます。
