# サポートフロー

文書更新日:2026-07-29

新規チケットを受け付けてから終了するまでの一般的な流れは、以下のとおりです。

1. お客様が新しいチケットを作成します。内容は、[新規チケット内容の確認](msp_check_new_ticket.md)の手順で確認します。

2. [サポート担当者を割り当てます](msp_assign_support_rep.md)。
  
3. チケットの内容が解決するまで、割り当てられたサポート担当者が対応します。対応中は、以下の操作を行います。

    * [ステータスの変更](msp_change_status.md)
    * [担当者の変更](msp_change_support_rep.md)
    * [コメントの追加](msp_add_comment.md)
    * [エスカレーション](msp_escalation.md)

4. チケットの内容が解決したら、お客様の了解を得て[チケットを終了します](msp_close.md)。
