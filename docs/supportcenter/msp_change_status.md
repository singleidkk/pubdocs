# ステータスの変更

文書更新日:2026-07-29

1. チケットを開き、**編集**をクリックします。
2. お客様への依頼内容をコメントに入力し、**ステータス**を**お客様ご対応待ち**へ変更します。
3. **送信**をクリックして確定します。

各ステータスの意味は、[チケットのステータス](status.md)を参照してください。

!!! info
    ステータスを変更すると、お客様へメールで通知されます。
