# SingleID サポートセンター

文書更新日:2026-07-29

SingleID サポートセンターは、SingleIDに関するお問い合わせをチケットとして登録し、進捗確認やサポート担当者との連絡を行うためのウェブ窓口です。過去のチケットも確認できます。

## 本ガイドの対象

本ガイドは、SingleIDをご利用のお客様と、お客様からのお問い合わせに対応するMSP提供事業者を対象としています。

## サポートセンターへのアクセス

1. SingleID 管理者ポータルのヘッダーにある**サポート**をクリックします。
2. メニューに表示される**サポートセンター**を選択します。
3. SingleID サポートセンターが別ウィンドウで表示されます。

!!! info
    SingleID サポートセンターを利用する管理者は、**SingleID 管理者ポータル＞管理＞管理者**画面で登録します。登録方法は、[管理者の登録](../singleid-adminguide/admin.md#管理者の登録)を参照してください。

## 受付方法

原則として、SingleID サポートセンターからお問い合わせください。

!!! info
    MSP提供事業者によっては、電話やメールでの受付窓口を設けている場合もあります。

## サポート対応時間

9:00～17:00（土曜日、日曜日、祝日、弊社休業日を除く）

## 受付内容

SingleIDに関する以下のお問い合わせを受け付けます。

* 設定や操作に関するお問い合わせ
* トラブルに関するお問い合わせ
* 作業のご依頼
* 契約ユーザ数の変更や解約など、契約に関するお問い合わせ
* お支払いに関するお問い合わせ

!!! info
    作業依頼の対応範囲は、MSP提供事業者によって異なります。

## 対応体制

お問い合わせには、MSP提供事業者またはSingleIDが対応します。
