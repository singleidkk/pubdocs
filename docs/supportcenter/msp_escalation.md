# エスカレーション

文書更新日:2026-07-29

チケットの対応にSingleIDまたはほかのMSP提供事業者の支援が必要な場合は、自組織専用の問い合わせ窓口にエスカレーション用のチケットを作成します。

1. チケットの**ステータス**を**エスカレーション中**へ変更します。
2. **プロジェクト**をクリックします。
3. 自組織専用の問い合わせ窓口を選択します。
4. **新しいチケット**をクリックします。
5. **説明**に、以下の情報を入力します。

    * お客様のアカウント番号
    * 顧客名
    * エスカレーションする内容

6. その他の必要事項を入力し、**作成**をクリックします。

!!! warning
    エスカレーション用のチケットは、お客様専用の問い合わせ窓口ではなく、自組織専用の問い合わせ窓口に作成してください。
