# エスカレーション

文書更新日:2026-07-29

チケットの対応にSingleIDまたはほかのMSP提供事業者の支援が必要な場合は、自組織専用の問い合わせ窓口にエスカレーション用のチケットを作成します。

## お客様のチケット

1. お客様のチケットを開き、**編集**をクリックします。
2. **ステータス**を**エスカレーション中**へ変更します。
3. **送信**をクリックして確定します。

## エスカレーション用のチケット

1. **プロジェクト**をクリックします。
2. 自組織専用の問い合わせ窓口を選択します。
3. **新しいチケット**をクリックします。
4. **説明**に、以下の情報を入力します。

    * お客様のアカウント番号
    * 顧客名
    * エスカレーションする内容

5. その他の必要事項を入力し、**作成**をクリックします。

!!! warning
    エスカレーション用のチケットは、お客様専用の問い合わせ窓口ではなく、自組織専用の問い合わせ窓口に作成してください。
