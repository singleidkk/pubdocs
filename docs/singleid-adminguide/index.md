# SingleID 管理者ガイド

文書更新日:2026-07-29

SingleID 管理者ポータルは、顧客アカウントの管理者が、ユーザ、認証、アプリ連携などを管理するためのウェブ管理画面です。

## 本ガイドの対象

SingleID 管理者ポータルを利用する顧客アカウントの管理者を対象としています。

## SingleIDのポータル

SingleIDには、利用者と目的が異なる以下のポータルがあります。

| ポータル | 利用者 | 主な用途 |
| :-- | :-- | :-- |
| SingleID 管理者ポータル | 顧客アカウントの管理者 | ユーザ、グループ、認証、アプリ連携、ログなどの管理 |
| [ユーザポータル](../singleid-userguide/index.md) | ユーザ | アカウント、パスワード、オーセンティケーター、セッションの管理 |
| [SingleID MSP管理者ポータル](../singleid-mspguide/index.md) | ディストリビュータおよび販売店 | 顧客アカウント、MSP/サポートアカウント、ポイントの管理 |

!!! warning
    SingleID 管理者ポータルおよびSingleID MSP管理者ポータルの操作は、PCのブラウザを使用してください。スマートフォンやタブレットなどの低解像度のデバイスでは、正しく表示されない場合があります。

## SingleID 管理者ポータルでできること

SingleID 管理者ポータルでは、管理者の権限に応じて、主に以下の操作を行います。

* ユーザとグループの管理
* RADIUS、LDAP、証明書による認証の設定
* アプリ連携の設定
* RADIUS認証ログと操作ログの確認
* セキュリティ診断の実行
* 組織アカウント、管理者、ネットワーク、詳細設定の管理

## 管理者ポータルのログイン

1. SingleIDの**[ログインページ](https://login.singleid.jp/)**へアクセスします。
2. **管理者ポータルログイン**をクリックします。
3. 管理者のアカウント情報でログインします。

!!! info
    * ログインでは、**パスワード認証**、**ワンタイムパスワード認証（2要素認証）**、**クライアント証明書認証**を利用できます。
    * **パスワード認証**および**ワンタイムパスワード認証（2要素認証）**でログインするときは、**ユーザ名**または**メールアドレス**を使用できます。

!!! warning
    一定期間内に複数回連続してログインに失敗すると、ユーザがロックアウトされます。しばらく経ってから、再度ログインしてください。

## 管理者ポータルのログアウト
1. ヘッダーの右端にある:fontawesome-solid-user-large: ボタンをクリックします。
2. メニューに表示される**ログアウト**を選択して、SingleID 管理者ポータルからログアウトします。

## 管理者ユーザポータルへの移動

管理者ユーザポータルでは、管理者自身のパスワード変更やワンタイムパスワード（OTP）トークンの設定を行います。

1. ヘッダーの右端にある:fontawesome-solid-user-large: ボタンをクリックします。
2. メニューに表示される**管理者ユーザポータル**を選択します。
3. 操作内容に応じて、以下の画面へ移動します。

    * パスワードを変更する場合: **管理者ユーザポータル＞パスワード**
    * ワンタイムパスワードのトークンを設定する場合: **管理者ユーザポータル＞オーセンティケーター**

!!! danger
    ワンタイムパスワードのトークンを設定すると、以後パスワードによるログインはできなくなります。トークンを紛失した場合は、他の管理者に依頼して対象の管理者アカウントを再作成してください。その管理者が唯一の管理者である場合は、サポートまでお問い合わせください。
