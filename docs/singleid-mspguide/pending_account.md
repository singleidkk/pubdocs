# 承認待ちアカウント管理

文書更新日:2026-07-28

**SingleID MSP管理者ポータル＞管理アカウント＞承認待ちアカウント一覧**画面には、自社で登録申請した未承認のアカウントが表示されます。

特権MSPおよびMSPアカウントの管理者は、権限の範囲内で申請内容を変更または削除できます。サポートアカウントの管理者は変更または削除できません。

## 申請内容の変更

1. 変更するアカウントの**編集**ボタンをクリックします。
2. 申請内容を変更し、**更新**ボタンをクリックします。

## 申請の削除

1. 削除するアカウントの**削除**ボタンをクリックします。
2. 確認画面の内容を確認し、**削除**ボタンをクリックします。

!!! warning
    削除した申請は復元できません。アカウントが必要な場合は、改めて登録を申請してください。
