# MSP管理者ガイド

文書更新日:2026-07-28

SingleID MSP管理者ポータルは、SingleIDのディストリビュータおよび販売店が、顧客アカウントやMSP/サポートアカウントを管理するためのウェブ管理画面です。

## 本ガイドの対象

SingleIDの特権MSP/MSP/サポートアカウントの管理者を対象としています。

## SingleID MSP管理者ポータルでできること

SingleID MSP管理者ポータルでは、管理者の権限に応じて、主に以下の操作を行います。

* 顧客アカウントの登録、変更、解約
* MSP/サポートアカウントの登録、変更、解約
* 承認待ちアカウントの確認、変更、削除
* 顧客アカウント、MSP/サポートアカウントのポイント変更
* ポイント履歴の確認
* 顧客アカウントへのサポートアカウント割当

!!! info
    サポートアカウントの管理者は、SingleID MSP管理者ポータルではアカウント情報の参照のみ可能です。顧客アカウントにサポートアカウントが割り当てられている場合は、顧客側のSingleID 管理者ポータルへ切り替えて、顧客環境の設定や確認を行うことができます。

!!! warning
    SingleID MSP管理者ポータルの操作は、PCのブラウザを使用してください。スマートフォンやタブレットなどの低解像度のデバイスでは、正しく表示されない場合があります。

## SingleID MSP管理者ポータルのログイン

1. SingleIDの**[ログインページ](https://login.singleid.jp/)**へアクセスします。
2. **管理者ポータルログイン**をクリックします。
3. 管理者のアカウント情報でログインします。
4. 必要に応じて、画面上部の**管理画面**ボタンをクリックし、SingleID MSP管理者ポータルへ切り替えます。

!!! info
    * ログインの認証方式とロックアウトの仕様は、[SingleID 管理者ポータルのログイン](../singleid-adminguide/index.md#管理者ポータルのログイン)を参照してください。

## 顧客画面への切り替え

SingleID MSP管理者ポータルから顧客アカウント側のSingleID 管理者ポータルへ切り替える場合は、画面上部の**顧客画面**ボタンをクリックします。

切り替え後は、左サイドメニュー上部の**顧客切り替え**から対象アカウントを選択します。
