# 無線LANアクセス-パスワード認証
文書更新日:2026-10-21

!!! warning
    本設定ガイドはレビュー中のドラフトです。記載内容は変更する場合があります。

## 目的

* SingleIDのユーザで、ELECOM 無線LANアクセスポイントへアクセスします。
* 接続する際の認証方式は、パスワード（PEAP、EAP-TTLS-PAP）です。
* SingleIDの拡張RADIUSサーバを利用します。
* ユーザ/グループによるアクセス制限をします。

## 設定方法

### SingleIDのグループの作成

1. **SingleID 管理者ポータル＞グループ**画面へ移動します。
2. **グループ追加**をクリックします。**グループ追加**画面がポップアップします。
3. **グループ名**を入力し、**登録**ボタンをクリックします。

### SingleIDのユーザの作成

1. **SingleID 管理者ポータル＞ユーザ**画面へ移動します。
2. **登録**ボタンをクリックします。**ユーザ登録**画面がポップアップします。
3. **ユーザ登録**画面の**基本情報**を入力します。**グループ**タブをクリックします。
4. メンバーとなるグループを選択し、**登録**ボタンをクリックします。

### SingleIDの拡張RADIUSサーバの登録

1. **SingleID 管理者ポータル＞認証＞RADIUS＞基本設定**タブへ移動します。
2. **拡張RADIUSサーバ＞RADIUSポート番号**の**登録**ボタンをクリックします。**拡張RADIUSサーバの登録**画面がポップアップします。

    | **設定項目** | **設定内容** |
    | :-- | :-- |
    | **使用するプロトコル** | **UDP**を選択します。 |
    | **シークレット** | 任意の半角英数字を設定します。英大文字、英小文字、数字を組み合わせた14文字以上の文字列を設定することをお勧めします。 |

3. **登録**ボタンをクリックします。専用のRADIUSポート番号が割り当てられます。

### SingleIDのRADIUSサイトの登録

1. **SingleID 管理者ポータル＞認証＞RADIUS＞簡易設定**タブへ移動します。
2. **カタログ表示**ボタンをクリックします。
3. カタログから**ELECOM 無線LANアクセスポイント**の**登録**ボタンをクリックします。**ELECOM 無線LANアクセスポイント**画面がポップアップします。
4. **基本情報**タブに、以下を設定します。

    | **設定項目** | **設定内容** |
    | :--- | :--- |
    | **有効/無効** | **有効**を選択します。 |
    | **サーバ** | **拡張**を選択します。 |
    | **サーバ番号** | [SingleIDの拡張RADIUSサーバの登録](#singleidの拡張radiusサーバの登録)の手順で登録したサーバ番号を選択します。 |
    | **サイト識別する属性** | **NAS-Identifier**を選択します。 |
    | **属性値** | `ap.mtk.com`を入力します。 |

    !!! info
        ELECOM 無線LANアクセスポイントは、`ap.mtk.com`をNAS-Identifierとして送信します。この値は機器側で変更できません。

5. **無線アクセスの認証**タブへ移動します。
6. **許可したいユーザ**および**許可したいグループ**をダブルクリックし、許可へ移動させます。

    !!! info
        接続可能なSSIDを制限したい場合には、**SSID**入力欄に接続を許可するSSIDを入力します。

7. **登録**ボタンをクリックします。

    !!! info
        設定がシステムに反映されるまで最大で15分かかります。

### ELECOM 無線LANアクセスポイントの設定

#### RADIUSサーバの設定

1. ELECOM 無線LANアクセスポイントのローカルWeb管理画面へログインします。
2. **無線設定＞RADIUS＞RADIUS設定**画面へ移動します。
3. 使用する周波数帯のプライマリRADIUSサーバを以下の内容で設定します。

    | **設定項目** | **設定内容** |
    | :--- | :--- |
    | **RADIUSタイプ** | **外部**を選択します。 |
    | **RADIUSサーバー** | **SingleID 管理者ポータル＞認証＞RADIUS＞基本情報**タブの**拡張RADIUSサーバ＞IPアドレス**の**プライマリ**です。 |
    | **認証ポート** | **SingleID 管理者ポータル＞認証＞RADIUS＞基本情報**タブの**拡張RADIUSサーバ＞RADIUSポート番号**のポート番号です。 |
    | **共有シークレット** | [SingleIDの拡張RADIUSサーバの登録](#singleidの拡張radiusサーバの登録)の手順の**シークレット**に設定した文字列です。 |
    | **セッションタイムアウト** | `86400`秒を設定します。（デフォルト値: 3600秒） |

4. セカンダリRADIUSサーバを以下の内容で設定します。

    | **設定項目** | **設定内容** |
    | :--- | :--- |
    | **RADIUSタイプ** | **外部**を選択します。 |
    | **RADIUSサーバー** | **SingleID 管理者ポータル＞認証＞RADIUS＞基本情報**タブの**拡張RADIUSサーバ＞IPアドレス**の**セカンダリ**です。 |
    | **認証ポート** | プライマリRADIUSサーバの**認証ポート**に設定したポート番号と同じです。 |
    | **共有シークレット** | プライマリRADIUSサーバの**共有シークレット**に設定した文字列と同じです。 |
    | **セッションタイムアウト** | `86400`秒を設定します。（デフォルト値: 3600秒） |

    [![ELECOM 無線LANアクセスポイントのRADIUSサーバ設定画面](/images/elecom-wab-be187-radius-server-guide.png)](/images/elecom-wab-be187-radius-server-guide.png)

5. **適用**ボタンをクリックします。

    !!! info
        * SingleIDは`Session-Timeout`属性を返さないため、機器に設定した**セッションタイムアウト**に従って再認証されます。
        * RADIUSサーバの応答待ち時間は変更できません。ファームウェアバージョン2.0.13での検証では、応答がない場合に約20秒ごとにプライマリとセカンダリを切り替え、再送処理は約33秒間継続しました。これらは実測値であり、ファームウェアや通信環境により変わる場合があります。

#### SSIDの設定

1. 使用する周波数帯に応じて、**無線設定＞2.4GHz＞基本設定**または**無線設定＞5GHz＞基本設定**画面へ移動します。
2. 以下を設定します。

    | **設定項目** | **設定内容** |
    | :--- | :--- |
    | **無線** | **有効**を選択します。 |
    | **有効SSID数** | 使用するSSID数を選択します。 |
    | **SSID** | 任意のSSIDを入力します。 |
    | **VLAN ID** | SSIDに割り当てる固定VLAN IDを入力します。 |

    [![ELECOM 無線LANアクセスポイントのSSID基本設定画面](/images/elecom-wab-be187-ssid-basic-guide.png)](/images/elecom-wab-be187-ssid-basic-guide.png)

3. **適用**ボタンをクリックします。
4. 使用する周波数帯の**セキュリティ**画面へ移動します。
5. 以下を設定します。

    | **設定項目** | **設定内容** |
    | :--- | :--- |
    | **SSID** | 設定するSSIDを選択します。 |
    | **認証方式** | **WPA Enterprise**を選択します。 |
    | **WPAタイプ** | **WPA2/WPA3 Enterprise**を選択します。 |
    | **暗号化タイプ** | **AES**を選択します。 |
    | **追加認証** | **追加認証なし**を選択します。 |

    [![ELECOM 無線LANアクセスポイントのSSIDセキュリティ設定画面](/images/elecom-wab-be187-ssid-security-guide.png)](/images/elecom-wab-be187-ssid-security-guide.png)

6. **適用**ボタンをクリックします。

    !!! warning
        SingleIDは、WPA3 Enterprise 192-bitをサポートしていません。**WPA3 Enterprise 192bit**は選択しないでください。
