# SCS評価制度に向けたリモートアクセスVPN認証強化
文書更新日:2026-10-05

SingleIDと対応するVPN装置を組み合わせ、リモートアクセスVPNへ2要素認証を適用する場合に、SCS評価制度の要求事項との関係を整理します。

本書で扱う認証方式は、パスワード認証とワンタイムパスワード認証の組み合わせ、およびパスワード認証とクライアント証明書認証の組み合わせです。

[![SCS評価制度に向けたリモートアクセスVPN認証強化の要約](/images/scs-remote-access-vpn-two-factor-authentication.svg)](/images/scs-remote-access-vpn-two-factor-authentication.svg)

!!! warning
    本構成だけでSCS評価制度の要求事項を満たすことを保証するものではありません。VPN装置の設定、VPN接続後のアクセス制御、申請・承認、棚卸、ログの保管・確認などを含めて評価してください。

## 対象とする認証方式

| 認証方式 | 認証要素 |
| :--- | :--- |
| パスワード認証＋ワンタイムパスワード認証 | パスワードを知識情報、OTPを所有情報として使用します。 |
| パスワード認証＋クライアント証明書認証 | パスワードを知識情報、クライアント証明書と秘密鍵を所有情報として使用します。 |

2要素認証として扱うには、VPN接続時に両方の認証要素を必須にします。パスワードのみ、またはクライアント証明書のみで接続できる経路を残さないでください。

## SCS評価制度との関係

### 4-1-1-1～4-1-1-4 ユーザIDの管理手続

SingleIDのユーザごとにVPN接続を認証し、不要になったユーザやVPN接続権限を無効化できます。

申請・承認、共有IDの抑制、退職・異動時の対応は、組織の運用手続として定めます。

### 4-1-3-1、4-1-3-3、4-1-3-4、4-1-3-5 認証の強度・実装方法の決定

パスワードとOTP、またはパスワードとクライアント証明書を組み合わせることで、異なる2種類の認証要素を使用する構成として整理できます。また、重要な機密情報を取り扱うシステムへインターネット経由で接続する場合の多要素認証を支援します。

次の内容を確認してください。

* VPN接続時に2つの認証要素が必須であること
* 多要素認証の知識情報に使用するパスワードが8文字以上であり、SingleIDのパスワードポリシーが適用されていること
* OTPの登録・解除、またはクライアント証明書の発行・失効を管理していること
* VPN装置に残るローカルユーザなど、2要素認証を経由しない接続方法を管理していること

### 4-1-7-1、4-1-7-2 アクセス権の管理ルール

SingleIDのユーザ・グループ単位でVPN接続の許可対象を設定できます。

VPN接続後の到達範囲を必要最小限に制限し、アクセス権の申請・承認、台帳管理、定期的な棚卸を実施してください。★4では、年1回以上のアクセス権の棚卸が求められます。

### 4-4-3-1～4-4-3-3 ログの取得

SingleIDのRADIUS認証ログで、VPN利用者のユーザIDと認証の成功・失敗を確認できます。

SCS評価制度で必要となるログ項目を確認し、不足する情報はVPN装置などのログと組み合わせて取得します。★4では、対象ログの6か月保管および認証ログの月1回以上の確認が求められます。また、ログの保存先へインターネット経由でアクセスする場合は、多要素認証を使用してください。

## 確認する設定・運用

* VPN接続時に2つの認証要素を必須にしていること
* VPN接続を許可するユーザまたはグループを限定していること
* VPN接続後のアクセス範囲を必要最小限に制限していること
* ユーザ、OTP、クライアント証明書、VPN接続権限の変更手続を定めていること
* VPN装置のローカルユーザと緊急時の接続方法を管理していること
* SingleIDとVPN装置のログについて、取得項目、保管期間、確認頻度を定めていること
* ログの保存先へインターネット経由でアクセスする場合は、多要素認証を使用していること
