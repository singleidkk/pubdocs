# 無線LANアクセスポイント 拡張RADIUSサーバ検証チェックシート

作成日:2026-09-05

このチェックシートは、自社の無線LANアクセスポイントについて、SingleIDのネットワーク機器連携カタログまたはネットワーク機器連携の設定例への掲載を希望するネットワーク機器ベンダーが、SingleIDとの連携を検証し、設定情報と検証結果を提出するための資料です。

* [パスワード認証・拡張RADIUSサーバ](https://pubdocs.singleid.jp/singleid-pocguide/wifiap/wlan-group-password-adv/)
* [クライアント証明書認証・拡張RADIUSサーバ](https://pubdocs.singleid.jp/singleid-pocguide/wifiap/wlan-group-cert-adv/)

各確認項目を記入してください。必須試験の結果欄には、**成功**、**失敗**、**対象外**、**未実施**のいずれかを記入してください。設定内容と画面遷移を確認できる画面キャプチャを提出してください。

## 2. NAS識別属性の確認

以下の手順で、無線LANアクセスポイントが送信する属性値を確認します。

2. **SingleID 管理者ポータル＞ログ＞RADIUS認証ログ**画面へ移動します。
3. 認証失敗ログの**NAS-IP**と**NAS-ID**を確認します。

## 3. SSIDの確認

SingleIDは、Called-Station-IdからSSIDを取得します。無線LANアクセスポイントの認証では、SSIDの有無を検証します。

以下の手順で確認します。

1. 無線LANアクセスポイントから認証します。
2. **SingleID 管理者ポータル＞ログ＞RADIUS認証ログ**画面へ移動します。
3. 該当する認証ログの**SSID**を確認します。
4. **SSID**が空欄の場合は、Called-Station-Idを`<無線LANアクセスポイントのMACアドレス>:<SSID>`の形式に設定できるか確認します。設定できる場合は、設定後に再度認証し、**SSID**が表示されることを確認します。

| **確認項目** | **確認結果** |
| :--- | :--- |
| SingleIDのRADIUS認証ログにSSIDが表示される | はい / いいえ |
| SSIDが表示されない場合、Called-Station-Idを`<無線LANアクセスポイントのMACアドレス>:<SSID>`の形式に設定できる | 可 / 不可 / 確認不要 |

## 4. RADIUS応答タイムアウトの確認

RADIUSサーバから応答がない場合に、無線LANアクセスポイントが応答を待つ時間を確認します。

| **確認項目** | **確認結果** |
| :--- | :--- |
| デフォルト値 |  |
| SingleID推奨値 | 5秒～10秒 |
| 5秒～10秒の範囲で設定できる | 可 / 不可 |

## 5. 再認証間隔の確認

再認証間隔は、接続中の無線LANクライアントに再度IEEE 802.1X認証を要求するまでの時間です。

| **確認項目** | **確認結果** |
| :--- | :--- |
| デフォルト値 |  |
| SingleID推奨値 | 86400秒（1日） |
| 86400秒（1日）に設定できる | 可 / 不可 |

!!! info
    SingleIDのクラウドRADIUSは、**Session-Timeout**属性をサポートしていません。無線LANアクセスポイントに設定した再認証間隔に従って再認証されます。

## 6. 認証キャッシュの確認

認証キャッシュは、無線LANクライアントの再接続やアクセスポイント間の移動時に、RADIUSによる再認証の頻度を抑えるために使用します。

| **確認項目** | **確認結果** |
| :--- | :--- |
| 認証キャッシュ機能の有無 | あり / なし |
| デフォルト値 | 有効 / 無効 |
| SingleID推奨値 | 有効 |
| キャッシュの有効期間 |  |

## 7. 必須試験

認証成功はパスワード認証とクライアント証明書認証で確認してください。

| **認証方式** | **試験項目** | **期待結果** | **結果** |
| :--- | :--- | :--- | :--- |
| パスワード | 許可ユーザが正しいパスワードで認証する | 無線接続成功およびSingleIDの認証成功 | 未実施 |
| パスワード | 誤ったパスワードで認証する | SingleIDの認証拒否および無線接続の拒否 | 未実施 |
| クライアント証明書 | 許可ユーザの有効なSingleIDクライアント証明書で認証する | 無線接続成功およびSingleIDの認証成功 | 未実施 |
| クライアント証明書 | 許可されていないユーザの証明書で認証する | SingleIDの認証拒否および無線接続の拒否 | 未実施 |
| クライアント証明書 | 失効したクライアント証明書で認証する | SingleIDの認証拒否および無線接続の拒否 | 未実施 |
| VLAN割り当て | RADIUSでVLANを割り当てたユーザで認証する | 指定したVLANへ接続 | 未実施 |
