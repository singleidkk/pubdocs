# クラウドRADIUSにおけるEAP-TTLS-PAPの提供一時停止のお知らせ

文書更新日:2026-11-27

平素よりSingleIDをご利用いただき、誠にありがとうございます。

SingleIDのクラウドRADIUSでは、認証方式の見直しに伴い、EAP-TTLS-PAPの提供を一時停止します。

| 項目 | 内容 |
| :--- | :--- |
| 対象サービス | SingleID クラウドRADIUS |
| 対象認証方式 | EAP-TTLS-PAP（EAP-TTLSの内部認証にPAPを使用する方式） |
| 提供停止日 | 2026年11月27日 |

## 影響

既存のお客様によるEAP-TTLS-PAPのご利用は確認されていないため、今回の提供停止による影響は見込んでいません。お客様側での設定変更は不要です。

EAP-TTLS-PAP以外の認証方式は、設定を変更することなく引き続きご利用いただけます。

## EAP-TTLS-PAPの利用を予定されている場合

EAP-TTLS-PAPを利用した導入を予定されている場合は、代替の認証方式をご案内しますので、SingleIDのサポート窓口までご相談ください。

再開時期を含む今後の提供方針は、決まり次第、本ページでお知らせします。

ご理解を賜りますよう、お願い申し上げます。
